# Oak & Ember Cafe

A static multi-page website for a fictional neighborhood cafe. Built with HTML, CSS, and a small amount of JavaScript. No frameworks.

This is a portfolio demo. The reservation form is validated in the browser only and does not send email.

---

## Pages

- `index.html` — Home
- `pages/menu.html` — Menu with category filters
- `pages/about.html` — Story
- `pages/visit.html` — Address and hours
- `pages/reserve.html` — Table request form

---

## Features

- Semantic HTML and basic SEO tags
- Sticky header and mobile three-line menu
- Menu filter: All, Coffee, Bakery, Brunch
- Responsive cards and split layouts
- Front-end reservation checks (name, email, date, time, guests)
